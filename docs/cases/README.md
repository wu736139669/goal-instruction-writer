identified where they appear.

## Reading the evidence

- **Public trace:** the open-source case links directly to PRs, comments,
  commits, and releases that readers can inspect.
- **Private-record audit:** the game, research, and SDK cases publish selected
  observations and sanitized evidence summaries. Input fingerprints identify
  inspected records; the raw private projects are not reproduced here.
- **Reusable contract:** the short contract in each new case is distilled from
  the work. It is an example to adapt, rather than a verbatim original prompt.

Project dates and test counts describe recorded stages. They do not measure
unattended agent time, independent adoption, or a causal speedup from this skill.
The maintainer's estimated 60+ hour workflow is discussed in the
[game case](factory-town-idle.md).

## Try a comparable task

own, and ask for a loop preview before drafting a long-running Goal. Keep the
authority, waiting conditions, and delivery boundary appropriate to your host.
