# Privacy and data handling

Effective October 19, 2026.

This statement covers the Goal Instruction Writer instruction package published
at https://github.com/wu736139669/goal-instruction-writer.

## What the package does

The plugin bundles Markdown instructions and references, UI metadata, and icons.
It helps the host agent preview, draft, refine, or audit Goal instructions.
The distributed runtime has no maintainer-operated server, MCP connection,
analytics collector, authentication flow, or executable script.

## Information used while working

Your request and any project information you make available can be used by your
host agent to write a Goal. A generated Goal can contain project details, paths,
acceptance criteria, evidence links, and checkpoints supplied during the task.
The host's permissions govern access to files and tools.

The package does not send prompts, files, generated Goals, or usage events to a
maintainer-controlled endpoint. It does not ask for account credentials or API
keys. No prompt or project-content retention is operated by the maintainer as
part of this package.

## Host providers and other services

Your host application and model provider process conversation and workspace
data under their own terms, privacy settings, and retention rules. This package
does not control those services or any tools you separately authorize.

The instructions do not authorize publishing your project or contacting other
people. If you separately request execution of a generated Goal, the host's
permissions and your authorization govern that work.

## Support and public contributions

The [GitHub issue tracker](https://github.com/wu736139669/goal-instruction-writer/issues)
and [Discussions](https://github.com/wu736139669/goal-instruction-writer/discussions)
are public. Information you post there is visible to other people and is hosted
by GitHub under its policies. For package privacy questions, use an issue with
the general question; keep private project content and credentials out of public
support posts.

Future changes to the package's data handling will be documented here with an
updated effective date.
