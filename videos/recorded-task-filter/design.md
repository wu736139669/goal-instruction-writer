# Design truth

Warm paper #f1efe7, dark green ink #182b25, accent #236d54, terminal #14221e,
terminal text #e6eee4. Flat editorial canvas, ruled dividers, restrained motion.
Headlines use bundled Montserrat 700. Commands, output, labels use bundled
IBM Plex Mono 400/700. Both are compiled into the build.

1920×1080; 72px side margins; 144px persistent header area; 1140px terminal
column and 552px annotation column with 48px gutter. Titles 60px, output 27px,
body 30px, recording disclosure 24px. No device mockups or synthetic UI chrome.

The transcript is the evidence and the CLI result is the payoff. Whole output
lines appear at authored replay cues. No fake keystrokes. Waterfall entry gives
headings a short directional arrival; cuts separate stages; a linear bottom
rule shows video progress rather than agent progress. Silence is deliberate:
this is a readable developer demonstration, with captions in the composition.


## Visual revision 2 — 2026-10-19 (current direction)

This section supersedes the original paper/green slide treatment above.
User note: the images/video look unattractive. Cause: six near-identical dense
panels, weak hierarchy, and a 90-second runtime for a small task.

Current cut: 48 seconds, 1920×1080, English-only. Dark ink #111714, warm paper
#f4f2e9, sharp lime #e2f471. Muted ink #5a655b, dark muted #bbc6b7, panel #1d2821,
border #3e4e41. A line highlight may use lime at 12% alpha. No other colors.

League Gothic 400 is the display face (106–184px); IBM Plex Mono 400/700 carries
code and facts (24–36px). Key content lives within x=192..1728. Square panels,
no shadows or glows. Six different compositions: oversized hook, connected
contract, source close-up, large proof numerals, contrasting result, direct CTA.
No paragraph walls, tiny editor chrome, generic gradient, or artificial UI.
Actual artifacts remain linked; labels distinguish contract summaries, exact
source, captured tests, and separate maintainer review. Motion guides attention
with short waterfall entrances, a measured code highlight, and path draw.
Silence remains deliberate; the new cut carries its story visually.
